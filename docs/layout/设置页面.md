# 设置页面设计与实现规划

## 1. 页面定位

设置页面仅配置 OpenAI SDK 兼容的模型连接信息，为 Qwen 翻译请求提供 Base URL、API Key 和模型名称。页面不承载翻译结果、历史记录、提示词编辑、主题、语言或高级生成参数。

## 2. 页面模块

| 模块 | 功能 |
|---|---|
| 顶部栏 | 返回侧边栏主页面，标识当前页面 |
| 模型连接表单 | 编辑 Base URL、API Key 和模型名称 |
| 安全提示 | 说明密钥保存在本地且只用于模型请求 |
| 保存反馈 | 显示保存成功或字段错误 |
| 底部操作区 | 保存设置 |

## 4. 字段与交互规则

### 4.1 OpenAI 兼容服务地址

- 必填。
- 仅接受有效的 HTTPS 地址。
- 首期以受信任的 Qwen OpenAI-compatible 服务地址为默认值或允许范围，避免申请任意主机权限。
- 保存时移除首尾空白，不在页面中拼接 API Key。

### 4.2 API Key

- 必填。
- 默认以密码形式隐藏。
- “显示 API Key”仅改变当前输入框可见性，不写日志、不复制、不发送到页面内容脚本。
- 编辑已有配置时不在 DOM、错误文案或日志中暴露完整密钥。

### 4.3 模型名称

- 必填。
- 使用 Qwen OpenAI-compatible 接口可识别的模型标识。
- 首期不提供模型市场、远程枚举或模型能力说明。

### 4.4 保存设置

- 点击后先执行字段校验，再写入配置存储区。
- 保存成功后显示简短反馈，可返回侧边栏发起翻译。
- 保存失败时保留用户输入，并在对应字段附近显示明确错误。
- 保存动作不自动上传网页正文，也不主动发起付费模型请求。

## 5. 页面流程

```text
从侧边栏进入设置
    |
    v
读取本地模型配置
    |
    v
编辑 Base URL / API Key / 模型名称
    |
    v

    |
    v

    |

    |

    |
    +--> 失败 --> 保存失败提示
    |
    v
保存成功 --> 返回侧边栏 --> 一键翻译
```

## 6. 功能模块实现步骤

### 阶段 1：设置页面骨架

1. 建立设置页面 React 入口和与侧边栏一致的简约视觉规则。
2. 创建顶部栏、模型连接表单、安全提示和底部保存操作区。
3. 使用受控表单管理三个配置字段及密钥可见状态。
4. 建立初始、编辑、保存中、保存成功和保存失败状态。

### 阶段 2：配置数据契约与读取

1. 定义版本化模型设置对象，字段限定为 Base URL、API Key 和模型名称。
2. 通过 Settings Repository 读取 Chrome Storage Local，不允许组件直接访问存储 API。
3. 将已有设置填充到表单；读取失败时显示可理解的错误。
4. 确保配置对象不包含网页正文、译文或调试信息。

### 阶段 3：校验与保存

1. 校验 Base URL 为允许的 HTTPS 服务地址。
2. 校验 API Key 和模型名称非空。
3. 对输入执行首尾空白清理，但不修改密钥内部字符。
4. 通过 Settings Repository 覆盖保存当前配置。
5. 保存后只显示成功状态，不在反馈中回显密钥。

### 阶段 4：与侧边栏联动

1. 从侧边栏设置入口打开设置页面。
2. 返回侧边栏时重新读取配置状态。
3. 配置完整后允许启动翻译；配置缺失时维持引导状态。
4. 验证模型配置不经过 Content Script，不进入跨页面文章消息。

### 阶段 5：安全与表单测试

1. 测试空字段、非 HTTPS 地址和不受信地址的错误反馈。
2. 测试密钥默认隐藏和显隐切换。
3. 测试读取、覆盖保存和存储失败场景。
4. 测试页面与日志均不暴露完整 API Key。
5. 测试保存设置不会自动调用模型服务。

## 7. 验收要点

- 页面只包含模型连接所需的三个字段。
- 用户可完成 Qwen OpenAI-compatible 连接配置。
- API Key 默认隐藏，且不进入日志、URL、正文消息或错误信息。
- 字段无效时不能保存，并能定位具体问题。
- 保存成功后，侧边栏可立即使用新配置发起翻译。
- 页面不出现历史、翻译风格、语言、主题和高级参数等冗余功能。
